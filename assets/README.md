# Assets

This folder contains app assets like icons and splash screens.

For production, you should replace these placeholder files with actual images:

- `icon.png` - App icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `splash.png` - Splash screen (1242x2436)
- `favicon.png` - Web favicon (48x48)

You can generate these using tools like:
- https://www.appicon.co/
- https://makeappicon.com/
- Or design your own using Figma, Adobe Illustrator, etc.

Recommended design:
- Use charity-related imagery (heart, hands, donation box)
- Primary color: #2196F3 (Blue)
- Keep it simple and recognizable
